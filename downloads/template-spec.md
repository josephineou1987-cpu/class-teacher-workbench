# 班主任工作台 · 模板需求与实现说明

## 目标

老师拿到网址后，可以立即了解页面、建立自己的班级并开始工作。需要自行改造时，下载现成源码交给 AI 修改，避免仅凭截图重新猜测页面与功能。页面简洁、少提示语，主要在电脑使用，也适配手机。

## 三个入口

1. 查看演示：进入 workspace.html?mode=demo，使用 36 人的虚拟班级。数据只在本次页面内存中变化，刷新即恢复，不读写个人班级资料。
2. 开始使用：无历史资料时，填写老师姓名、班级名称与学期，进入空白工作台。使用 sessionStorage 传递建班信息，再以 localStorage 持久化。
3. 继续使用：若当前浏览器已有 classdesk-v1 数据，直接继续原班级，不覆盖。
4. 下载模板包：下载完整静态网页、MD 说明、AI 修改指令及依赖许可。入口页另可单独下载本 MD。

## 设计约定

- 外围淡紫色，主内容浅灰，侧栏和内容卡片白色。
- 主色约 #7858fa；紫色集中于一张主视觉卡、主要按钮和选中状态；大片内容保持白色。
- 大圆角、轻边框或无边框，无厚重阴影。标题深灰，正文清楚可读。
- 电脑首页分为侧栏、主区和右侧日历提醒区。主区包含紫色主卡、五个快捷操作、六项统计和图表。
- 手机侧栏改抽屉，常用快捷操作保留，表格横向滚动。
- 页面内容熟悉可操作，避免长篇功能解释和重复宣传词。

## 技术与文件结构

纯 HTML、CSS、JavaScript，无框架、无构建要求。所有运行依赖都在本地文件中；第三方为 Lucide 图标和 docx，保留 licenses 下许可。默认静态根目录的 index.html 为分享入口，workspace.html 为工作台，app.js 为业务逻辑，style.css 为工作台样式，welcome.* 为入口。

源码包不应包含部署项目 ID、Git 历史、原作者账号信息、令牌或个人业务数据。

## 数据结构与保存

- localStorage 键：classdesk-v1。结构版本 version: 1。
- settings：teacher、className、term、pass、excellent。
- students：id、number、name、gender、phone、height、myopia、front、evaluation，及 pet、points、xp、food、mood、clean、decor。
- exams：id、title、date、scores；每条成绩含 student 及语文、数学、英语分数。
- discipline、leaves、homework、work、talks、contacts、activities：独立记录数组；关联学生使用学生 id。
- todos、notes、links、points：待办、笔记、链接、积分记录。
- seat：rows、cols、aisle、ids；seatHistory 保存历史方案。
- 删除学生时清理关联业务记录、作业提交状态、成绩与座位中的引用。
- 照片压缩后以 data URL 保存在记录内。浏览器存储有容量限制，保存失败须提示并引导备份。
- 本版本没有服务器数据库、账号密码、云端同步或多人协作。每台设备、浏览器和网址下的数据独立。

## 导入导出

学生导入以学号匹配更新；文件必须包含学号、姓名，支持性别、家长电话、身高、近视、优先前三排、综合评价。成绩导入以学号和姓名匹配，验证三科为 0–100。

支持 XLSX / CSV，不支持旧 .xls。XLSX 使用标准 ZIP + XML 写出，支持读取常见 deflate 压缩的首张工作表；浏览器需支持 DecompressionStream。Word 使用 docx 库导出真正的 .docx，座位表用 Canvas 导出 .png。全量备份为 JSON，可包含照片和宠物记录。

## 当前边界与后续扩展

- 默认科目仅语文、数学、英语，默认满分 100；扩科与不同满分需要同时修改数据结构、模板、校验、图表和排名。
- 请假为表单录入，尚无四步向导。
- 积分由教师手动管理，尚无自动奖惩规则、学生单独操作端和物品背包。
- 宠物等级 1–100，成长值每 100 升一级；饱食、心情、清洁由操作改变，暂无定时衰减。
- 座位为属性优先排序，尚无复杂约束求解；“必须前三排”超出容量时需要新增冲突提示。
- 密码设置、真实账号登录与云端共享尚未实现。若扩展，需要后端、身份认证、按用户隔离和备份方案。

## 验收要点

1. 无登录可打开分享入口，三个入口可点击，下载文件存在。
2. 查看演示不会修改已保存个人班级，刷新后演示复原。
3. 首次使用创建空白班级，姓名和班级正确；再次访问显示继续使用。
4. 录入资料刷新后保留，导出备份后可恢复。
5. 学生与成绩模板能导入，XLSX / DOCX / PNG 导出可打开。
6. 手机入口可读、侧栏可打开，主要按钮可点击。
7. 下载包解压可运行，不含原站点身份；修改后可独立发布。

## 从零生成时给 AI 的要求

若无法提供源码，请按以上结构制作最小可用版本：先完成静态入口、学生与日常记录、存储和备份，再补图表、导出和成长宠物。明确标出未完成项，不要用空按钮代替已实现功能。若有源码，优先在源码上修改。
